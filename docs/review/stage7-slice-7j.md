# スライス 7j の敵対的レビューで、直さずに記録した指摘

実施日: 2026-11-14。対象は suchi/sucheme-zig#302(REPL への行編集の組み込み)。担当は2本で、1本はミューテーション(テストの強さ)、もう1本は疑似端末で実行ファイルの挙動を広く試した。指摘の重要度は帰結で決める([ADR-0027](../adr/0027-severity-by-consequence-and-a-cost-side-stop.md))。本ファイルへの指摘は任意を上限とする。

同じ PR で直したものは書かない。直したものは、次のとおりである。

- ミューテーションで区別されていなかった分岐のテスト。
- 改行で終わらない出力が、次のプロンプトで消えること。
- Esc のあとの制御キー。
- 評価中の Ctrl-C の文書。
- ガイドの制限の書き方。

## 直さずに記録するもの(任意)
