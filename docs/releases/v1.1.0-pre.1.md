# sucheme v1.1.0-pre.1

sucheme-zig の先行版(pre-release)である。Zig で作る R7RS-small 準拠の Scheme インタプリタで、段階7(REPL の行編集)の途中までを含む。試用のために切った版で、段階7が終わった版ではない。段階7の残り(識別子の補完、差分読み取り)は入っていない。

ライセンスは付与していない(UNLICENSED、全権利保留。[ADR-0022](https://github.com/suchi/sucheme-zig/blob/v1.1.0-pre.1/docs/adr/0022-unlicensed-proprietary.md))。

## v1.0.0 からの変更

REPL の行編集が入った。標準入力と標準出力の両方が端末のときだけ働き、パイプとファイルの入力は、これまでどおり1行ずつ読む。

- Emacs 風のキー割り当て(カーソル移動、語単位の移動、切り取りと貼り付け、取り消し)で、打っている行を編集できる。
- 履歴を、上下の矢印と Ctrl-R(後ろ向きの増分検索)で呼び出せる。履歴は、環境変数 `SUCHEME_HISTORY` のパス(無ければホームの下の `.sucheme_history`)のファイルに保存し、次の起動で読む。
- 閉じていない式は継続行になり、前の行へ戻って直せる(複数行の編集)。
- カーソルの位置と対になる括弧を、反転表示で示す。
- Windows のコンソールでも、行編集が働く。

キー割り当ての一覧と注意は、[docs/manual/guide/03-repl.md](https://github.com/suchi/sucheme-zig/blob/v1.1.0-pre.1/docs/manual/guide/03-repl.md) にある。

## 取得の確認

`SHA256SUMS` と同じディレクトリで、次を実行する。

```sh
sha256sum -c SHA256SUMS
```

`SHA256SUMS` は成果物と同じ場所から配るので、破損や取り違えには効くが、改ざんには効かない。署名と attestation は行っていない([ADR-0034](https://github.com/suchi/sucheme-zig/blob/v1.1.0-pre.1/docs/adr/0034-release-shape.md))。

## 使い方

```sh
tar xzf sucheme-v1.1.0-pre.1-x86_64-linux-musl.tar.gz
./sucheme-v1.1.0-pre.1-x86_64-linux-musl/sucheme --version    # sucheme 1.1.0-pre.1
./sucheme-v1.1.0-pre.1-x86_64-linux-musl/sucheme              # REPL
./sucheme-v1.1.0-pre.1-x86_64-linux-musl/sucheme prog.scm     # ファイルのプログラムを実行する
```

REPL とファイルの最初の環境は `(scheme base)` である。`display` は `(scheme write)` にあるので、使う前に `(import (scheme write))` を実行する。REPL は、Linux と macOS の端末では Ctrl-D、または `(import (scheme process-context))` のあとの `(exit)` で終える。そのほかの使い方は [v1.0.0](https://github.com/suchi/sucheme-zig/blob/v1.1.0-pre.1/docs/releases/v1.0.0.md) のリリースノートと同じである。

## 既知の制限

- 識別子の補完(Tab)は無い。Tab は文字として入る。
- Windows のコンソールの行編集は、実機のコンソールで走らせて確かめていない。Windows 向けのコードのコンパイルと、定数の固定のテストだけを確かめている。キー入力や再描画が崩れる可能性がある。崩れたときは、パイプで入力すると、行編集のない読み方に切り替わる。
- 文字幅は仮の実装で、全角の文字を含む行は、カーソルの位置がずれることがある([ADR-0049](https://github.com/suchi/sucheme-zig/blob/v1.1.0-pre.1/docs/adr/0049-line-editor-in-zig-minimal-core-first.md))。
- 評価の間の Ctrl-C は、sucheme を終える。評価だけを止める手段は無い。
- [docs/manual/guide/03-repl.md](https://github.com/suchi/sucheme-zig/blob/v1.1.0-pre.1/docs/manual/guide/03-repl.md) は、Windows の行編集、括弧の対応の表示、履歴の保存の記述が実装に追いついていない箇所がある。実装の挙動が正である。
- v1.0.0 の既知の制限(実行時エラーに位置が付かない、性能が暫定など)は、そのまま残っている。

## 動作保証の範囲

- 実行して確かめた: Linux x86_64 の成果物を、`--version` と簡単な式の評価で確かめた。テストは Linux x86_64 で自動で走る。Windows x86_64 のテストは、層2 で走る。
- ビルドだけ確かめた: Windows、macOS、Linux aarch64、Windows aarch64 の実行ファイル。macOS は署名も公証もしていない。
- 問題が見つかった場合は、issue で知らせてほしい。
