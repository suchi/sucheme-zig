# ADR-0044: 機械の歩数の上限は、周回を数え、ハンドラで捕まえられない誤りで形式を打ち切る

- ステータス: 採用
- 日付: 2026-10-21

スライス 6h-1([plans/0024-step-limit-for-the-conformance-run.md](../plans/0024-step-limit-for-the-conformance-run.md))の判断で、計画書の「合意を求める点」として 2026-10-21 に決めた。

## 背景

スライス 6f から、全コミットの CI の `zig build check-report` が、取り込んだ準拠スイートを毎回すべて走らせる。スイートの形式が止まらなくなると、ジョブの `timeout-minutes: 20` だけが止め、どの形式で止まらなくなったかが出力に出ない。

[ADR-0004](0004-cek-machine-evaluator.md) と [ADR-0009](0009-wasm-freestanding-and-zero-dependency-web-ui.md) は、機械が歩数の制限で制御を戻す構造を目標として挙げ、段階8の再開可能な機械(`sucheme_step`)で入れるとしている。準拠スイートの実行器は、段階8を待たずに、止まらない形式を打ち切る手段を要る。

## 決定

1. 単位: 機械の `steps` のループの1周を1歩と数える。1周は、節点を1つ評価するか、継続のフレームを1つ適用する。プリミティブの呼び出しは、中で何をしても1歩である。数える範囲は `Machine.run` の1回(最上位の形式1つ)で、`run` のたびに残りを上限に戻す。`import` が読み込むライブラリの本体は、形式ごとに `Machine.run` を呼ぶので、本体の形式ごとに数え直す。最上位の `import` 1つは、本体の形式の数だけ上限まで走れる。
2. 上限に達したら、機械は `error.StepLimit` を返す。Scheme の条件としては送出しない。例外ハンドラには渡さず、`dynamic-wind` の `after` も呼ばない。`Interpreter.diagnostic` の文言は `step limit exceeded` である。
3. 上限は `Interpreter.setStepLimit(?u64)` で置く。既定は上限なし(null)で、REPL、ファイルの実行、WASM は上限を置かない。
4. 段階8の再開可能な機械は、同じ残りの数を使い、上限に達したら誤りでなく状態コードで制御を戻す形に広げてよい。この ADR は打ち切りだけを決め、再開の形は決めない。

検討して選ばなかったもの:

- 時間の上限: ランナーの速さで結果が変わり、CI の生成物(`docs/status/conformance.md`)が機械によって変わる。
- 確保の量の上限: 確保をしないループ(`(let loop () (loop))`)を止められない。
- 手続きの適用ごとに数える: 1歩の重さが手続きの本体の長さで変わる。止まらない計算が必ず手続きの呼び出しを通ることを、展開器が作る形ごとに確かめる必要がある。
- Scheme の条件として送出する(`heap limit exceeded` と同じ形): `(chibi test)` の `test` は、`with-exception-handler` でテストの式が上げた条件を捕まえて記録し、次へ進む。条件にすると、捕まえて続ける式が止まらない。上限を一度超えたあとに、次の歩ごとに送出し直すかどうかの規則も要る。

## 結果

- メリット: 決定的で、CI の生成物が機械の速さで変わらない。確保の有無によらず、止まらないループを止める。数える場所が機械の1か所である。ハンドラが握りつぶせない。
- デメリット・受け入れたトレードオフ:
  - 周回ごとに残りを比べて減らす費用が乗る。6h-1 の測定では、上限なしの退行は、ばらつきの幅(数%)を超えて見えなかった(値は計画書 0024 の「測定」)。
  - 上限に達した形式の `dynamic-wind` の `after` は呼ばれない。利用者のプログラムが上限の超過を捕まえて後始末することはできない。今は REPL で上限を置かないので、利用者には現れない。
  - マクロの展開は機械の外で走るので、止まらない展開はこの上限では数えない(roadmap の段階3の「マクロの展開の有界化の残り」の (1))。
- 将来の見直し条件: REPL や WASM で上限を利用者に見せるとき(`after` の扱いと、捕まえられるかを決め直す)。段階8で再開可能な機械を入れるとき(残りの数の持ち方を、レジスタの一部として決め直す)。
