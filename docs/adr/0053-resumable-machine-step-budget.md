# ADR-0053: 機械は歩数の予算で制御を戻し、停止中のレジスタを GC のルートにして、続きから再開できる

- ステータス: 採用
- 日付: 2026-11-21

スライス 8e-1([plans/0030-phase8-web-ui.md](../plans/0030-phase8-web-ui.md) の決定2)の設計である。計画書の合意で、方式(機械のレジスタを持続する状態にし、`step(budget)` で進める)は決まっている。この ADR は、実装で選んだ細部を記録する。

## 背景

`Machine.run` は、レジスタを局所変数に置いて完了まで走る。ブラウザでは、長い評価の間に画面が応答せず、停止は Worker を捨てる形で、それまでの定義が失われる([design/platform-and-web.md](../design/platform-and-web.md) の再開可能性)。[ADR-0044](0044-machine-step-limit-not-catchable.md) の決定4は、同じ残りの数を使って制御を戻す形に広げてよいとしている。[ADR-0031](0031-gc-at-machine-step-boundaries.md) により、GC は歩の境目で走るので、制御を戻す位置と一致する。

## 決定

1. 機械は、`begin(root)` で実行を始め、`step(budget)` で最大 `budget` 歩進めて、`Outcome` で戻る。`Outcome` は、`done`(値)、`more`(予算を使い切った)、`interrupted`(割り込みの要求を見た)、`needs_input`(入力待ち)である。`needs_input` は、返し方と再開の意味を 8f-1 が決める。8e-1 では返さない。
2. レジスタは `Machine.regs` に持つ。`more`、`interrupted`、`needs_input` で戻るとき、レジスタを `Context.parked` に写し、`Context.mark` が辿る。再開で外し、`done` と誤りの終了でも外す。停止中の GC のルートは、`Context` の表と `parked` だけになる。停止中に `Machine` を動かしてはならない。
3. 歩数の数え方は、ADR-0044 の決定1のまま(周回の1回を1歩)である。1周ごとに比べる数は1つにする。`step` の入りで、予算と歩数の上限の残りの小さいほうを局所の数にし、出るときに両方から使った歩数を引く。両方が同時に尽きたら、上限が先で、`StepLimit` で終える(ADR-0044 の決定2は変わらない)。上限だけが尽きたときは `more` でなく `StepLimit` を返す。
4. 割り込みの要求は、`Context.interrupt`(アトミックな真偽値)に外から立てる。`step` は、周回の先頭で見て、`interrupted` で戻り、要求を降ろす。立てる側(ネイティブの信号ハンドラ、WASM のホスト)は含めない(計画書の決定7)。
5. `Machine.run` は、`begin` と、予算の無い進め方の組み合わせで、割り込みの要求を見ない。ネイティブの挙動と周回の費用は、見る処理を持たない形(コンパイル時に外す)で変えない。
6. 入れ子の実行(ライブラリの本体を走らせる `Machine.run`、`environment` の輸入集合)は、`run` を通り、予算を数えず、割り込みを見ない。外側の `step` の1歩の中で完了まで走る。
7. `Interpreter` は、`evalPrint` の局所変数だった状態(リーダ、位置の表、コンソールの退避、機械)を `Eval` にまとめ、`beginEval`、`stepEval(budget)`、`abortEval` を足す。`evalPrint` は、割り込みを見ない進め方で完了まで回す層である。`import` と `define-library` の形式は、予算を数えず1回で済ませる。1回の `stepEval` が複数の形式をまたぐときは、1つの予算を共有する。誤りは、`stepEval` が `diagnostic` を整えて返す。

## 結果

- メリット: 停止と入力待ちが、同じ仕組みで実現できる。停止しても、それまでの定義が残る(`abortEval` は評価を捨てるだけで、ヒープと環境に触れない)。ネイティブの挙動は変わらない。
- デメリット・受け入れたトレードオフ:
  - 入れ子の実行は中断できない。長いライブラリの読み込みや、本体が止まらないライブラリの `import` の間、ホストは制御を取り戻せない。利用者向けの文書の Web UI の節に影響するので、8e-2 が、その節を書くときに扱う。
  - マクロの展開と、リーダの読み取りは、機械の外で走るので、予算に数えない(ADR-0044 の結果と同じ)。
  - 評価の間、呼び出し側は、`arena`、`source`、`out` を保持する。評価は同時に1つだけである。
  - 周回ごとに、予算の局所の数の比較が1つ乗る(置き換えであり、上限の比較と同じ数である)。`step` 側は、割り込みの確認が1つ加わる。費用の測定は PR にある。
- 将来の見直し条件: 8f-1 で `needs_input` を返すとき(再開の意味)。ネイティブの Ctrl-C で割り込みを立てるとき(信号ハンドラからの立て方)。入れ子の実行を中断できるようにするとき。
