# 進捗の自動生成物

このディレクトリのファイルは生成物である。手で編集しない。

| ファイル | 生成元 | 生成されるようになる段階 |
| --- | --- | --- |
| `conformance.md` | `tests/r7rs-required/` の識別子一覧、`lib/` のエクスポート、意味論テストの結果、準拠テストスイートの結果 | 段階3 |

生成は `zig build report` で行う。CI は生成し直した結果が現在のファイルと一致するかを検査し、一致しない場合は失敗させる。これによりドキュメントがコードから乖離しない。

CI からの自動コミットは行わない。ブランチ保護と衝突し、レビューを経ない変更が入るためである。

マトリクスの定義は [../design/r7rs-coverage.md](../design/r7rs-coverage.md) にある。
