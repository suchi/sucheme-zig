# 進捗の自動生成物

このディレクトリのファイルは生成物である。手で編集しない。

| ファイル | 生成元 |
| --- | --- |
| `conformance.md` | `tests/r7rs-required/` の識別子一覧と、インタプリタがその識別子を束縛しているか(段階1の最小版) |

生成は `zig build report` で行う。CI は `zig build check-report` で、生成し直した結果が現在のファイルと一致するかを検査し、一致しない場合は失敗させる。これによりドキュメントがコードから乖離しない。束縛を増やす変更は、`zig build report` を実行して、更新した `conformance.md` を同じコミットか PR に含める。

入力を足す段階は次のとおりである。段階1の最小版は、これらを読まない。

- 段階3: `lib/` のエクスポート節
- 段階6: 準拠テストスイート(`r7rs-tests.scm`)の結果

CI からの自動コミットは行わない。ブランチ保護と衝突し、レビューを経ない変更が入るためである。

マトリクスの定義は [../design/r7rs-coverage.md](../design/r7rs-coverage.md) にある。
