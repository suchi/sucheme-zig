# 18 入出力

これまでは、`display` と `newline` で画面に出すだけでした。この章では、データを書き出す `write`、データを読み込む `read`、ファイルの読み書きを学びます。

Scheme の入出力は、ポート(port)という値を通して行います。ポートは、文字やバイトの出入り口です。画面(標準出力)、文字列、ファイルが、どれも同じポートとして扱えます。Python の file object や、Java の `Reader` と `Writer` に当たります。

この章で使う手続きは、`(scheme write)`、`(scheme read)`、`(scheme file)` に入っています。

```scheme
(import (scheme base) (scheme write) (scheme read) (scheme file))
```

## display と write

`display` は人が読む形、`write` はデータとして読み直せる形で出します。違いが出るのは、文字列と文字です。

```scheme
(display "hello")
(newline)
(write "hello")
(newline)
(display #\a)
(newline)
(write #\a)
(newline)
```

```output
hello
"hello"
a
#\a
```

`write` は、文字列を二重引用符で囲み、文字を `#\a` の形で出します。文字列の中の二重引用符と改行は、バックスラッシュで書き表します。

```scheme
(write "say \"hi\"\n")
(newline)
(write '(1 "two" #\3 sym 4.5))
(newline)
(display '(1 "two" #\3 sym 4.5))
(newline)
```

```output
"say \"hi\"\n"
(1 "two" #\3 sym 4.5)
(1 two 3 sym 4.5)
```

リストの中でも、`display` は中身を `display` の形で、`write` は `write` の形で出します。ベクタ、バイトベクタ、有理数、空のリストも出せます。

```scheme
(write (list #t #f '() 1/3 -0.0 #(1 2) #u8(1 2)))
(newline)
```

```output
(#t #f () 1/3 -0.0 #(1 2) #u8(1 2))
```

`write` が出したものは、`read` で同じデータに読み戻せます。これが、データをファイルに保存したり、別のプログラムに渡したりする土台になります。

## 出力ポート

`display`、`write`、`newline` は、2番目の引数に出力ポートを取れます。省略すると、現在の出力ポート(画面)に出ます。

`open-output-string` は、文字を溜める出力ポートを作ります。溜めた文字列は `get-output-string` で取り出せます。

```scheme
(define out (open-output-string))
(write 'sym out)
(write-char #\space out)
(write-string "text" out)
(display 42 out)
(get-output-string out)
```

```output
"sym text42"
```

`write-string` は文字列を、`write-char` は1文字を、そのまま(引用符なしで)書き込みます。画面に出す手続きを、ポートを受け取る形に書いておくと、画面にも文字列にもファイルにも使えます。

```scheme
(define (print-pair p port)
  (write (car p) port)
  (write-string " => " port)
  (write (cdr p) port)
  (newline port))

(print-pair '("key" . 1) (current-output-port))
(define buffer (open-output-string))
(print-pair '(b . 2) buffer)
(get-output-string buffer)
```

```output
"key" => 1
"b => 2\n"
```

`(current-output-port)` は、現在の出力ポートを返します。

## 循環構造と共有

リストの最後の `cdr` を先頭に結ぶと、終わりのない循環したリストができます。`write` は、循環があるデータを、データラベル(`#0=` と `#0#`)で書き表します。

```scheme
(define loop (list 1 2 3))
(set-cdr! (cddr loop) loop)
(write loop)
(newline)
```

```output
#0=(1 2 3 . #0#)
```

`#0=` は、このデータに0番のラベルを付けるという意味で、`#0#` は、0番のラベルのデータをここに置くという意味です。`display` も同じ形で出します。ラベルがなければ、`write` は終わらなくなります。

同じデータを2か所から指しているだけで、循環していないときは、`write` はラベルを付けません。ラベルを付けて共有を見せたいときは `write-shared` を使います。ラベルを一切付けない `write-simple` もあります(循環したデータに使うと終わりません)。

```scheme
(define shared (list 1 2))
(define pair-of-shared (list shared shared))
(write pair-of-shared)
(newline)
(write-shared pair-of-shared)
(newline)
(write-simple pair-of-shared)
(newline)
```

```output
((1 2) (1 2))
(#0=(1 2) #0#)
((1 2) (1 2))
```

## read でデータを読む

`read` は、入力ポートから、Scheme のデータを1つ読みます。式を評価はしません。読んだ結果は、リスト、シンボル、数などのデータです。

```scheme
(define in (open-input-string "(a . b) 42 \"s\" #t foo"))
(read in)
(read in)
(read in)
(read in)
(read in)
(read in)
```

```output
(a . b)
42
"s"
#t
foo
#<eof>
```

`open-input-string` は、文字列を読む入力ポートを作ります。読み終わると、`read` は終わりを表す値(EOF オブジェクト)を返します。この値は `eof-object?` で調べます。`(eof-object)` で作ることもできます。

すべてのデータを読んでリストにまとめる手続きを書きます。

```scheme
(define (read-all port)
  (let loop ((x (read port)) (acc '()))
    (if (eof-object? x)
        (reverse acc)
        (loop (read port) (cons x acc)))))

(read-all (open-input-string "1 (two 3) \"four\""))
(read-all (open-input-string ""))
```

```output
(1 (two 3) "four")
()
```

`read` は、式を評価しません。`(+ 1 2)` と書かれていても、読んだ結果は3要素のリストで、計算はされません。

```scheme
(define form (read (open-input-string "(+ 1 2)")))
form
(car form)
```

```output
(+ 1 2)
+
```

文法に合わない入力を読むと、誤りになります。`read-error?` で、読み取りの誤りかどうかを調べられます。

```scheme
(guard (e ((read-error? e) 'bad-input))
  (read (open-input-string "(1 2")))
```

```output
bad-input
```

## 行や文字で読む

データでなく、行や文字を読む手続きもあります。

- `(read-line port)`: 1行を文字列で読む。改行は含まない。
- `(read-char port)`: 1文字を読む。
- `(peek-char port)`: 1文字を、読み進めずに見る。
- `(read-string k port)`: 最大 k 文字を、文字列として読む。

```scheme
(define text (open-input-string "first line\nsecond line\nrest"))
(read-line text)
(read-char text)
(peek-char text)
(read-string 5 text)
(read-line text)
(read-line text)
```

```output
"first line"
#\s
#\e
"econd"
" line"
"rest"
```

`read-line` と `read-char` は、読むものが無くなると EOF オブジェクトを返します。

```scheme
(eof-object? (read-line text))
```

```output
#t
```

## ファイルの入出力

ファイルは、ファイルのポートを開いて読み書きします。次の手続きは `(scheme file)` にあります。

- `(call-with-output-file ファイル名 手続き)`: ファイルを書き込み用に開き、ポートを手続きに渡す。手続きが終わると、ポートを閉じる。
- `(call-with-input-file ファイル名 手続き)`: ファイルを読み込み用に開き、ポートを手続きに渡す。手続きが終わると、ポートを閉じる。
- `(file-exists? ファイル名)`: ファイルがあるかを返す。
- `(delete-file ファイル名)`: ファイルを消す。

`call-with-input-file` は、ポートを自動で閉じるので、閉じ忘れがありません。Python の `with open(...)` に当たります。

ファイルに触れる例は、プログラムをファイルとして実行して見せます。ここからのコマンドの例は、どれも `zig build check-examples` が、`tutorial/examples/` の下で実行ファイルを走らせて確かめています。作業ディレクトリは、ファイル名の基準になります。

次の `cat.scm` は、最初の引数のファイルを、行番号をつけて出します。コマンドライン引数は第19章で説明するので、ここでは「`sucheme cat.scm ファイル名` と打つと、`ファイル名` を読む」とだけ理解してください。

`cat.scm` の内容です。

```text
(import (scheme base) (scheme write) (scheme file) (scheme process-context))

(define (show-lines port n)
  (let ((line (read-line port)))
    (unless (eof-object? line)
      (display n)
      (display ": ")
      (display line)
      (newline)
      (show-lines port (+ n 1)))))

(call-with-input-file (cadr (command-line))
  (lambda (port) (show-lines port 1)))
```

`fruits.txt` には、`apple`、`banana`、`cherry` が1行ずつ書いてあります。

```console
$ sucheme cat.scm fruits.txt
1: apple
2: banana
3: cherry
```

次の `roundtrip.scm` は、データを `write` でファイルに書き、`read` で読み戻して、最後にファイルを消します。

```text
(import (scheme base) (scheme write) (scheme read) (scheme file))

(define name "roundtrip.tmp")

(call-with-output-file name
  (lambda (port)
    (write '(point (x . 1) (y . 2)) port)
    (newline port)
    (write "a \"quoted\" word" port)
    (newline port)))

(display (file-exists? name))
(newline)

(call-with-input-file name
  (lambda (port)
    (let* ((first (read port))
           (second (read port))
           (third (read port)))
      (write first)
      (newline)
      (write second)
      (newline)
      (write (eof-object? third))
      (newline))))

(delete-file name)
(display (file-exists? name))
(newline)
```

```console
$ sucheme roundtrip.scm
#t
(point (x . 1) (y . 2))
"a \"quoted\" word"
#t
#f
```

`write` で書いたデータは、`read` で、書いたときと同じデータに戻ります。文字列の中の二重引用符も、正しく戻っています。

## ファイルが無いとき

存在しないファイルを開くと、ファイルの誤りになります。`file-error?` で調べられます。

```scheme
(guard (e ((file-error? e) 'no-such-file))
  (open-input-file "this-file-does-not-exist.txt"))
```

```output
no-such-file
```

調べなければ、プログラムは誤りで止まり、終了コードは 1 です。

```console
$ sucheme missing.scm
error: file operation failed in open-input-file "this-file-does-not-exist.txt"
[exit 1]
```

## 練習問題

1. リストの各要素を `write` の形で、1行に1つずつ、出力ポートに書き出す手続き `write-lines` を書いてください。文字列ポートに書いて、結果の文字列を確かめてください。
2. 文字列を `read` で全部読み、数だけを集めてリストにする手続き `numbers-in` を書いてください。`"1 a 2.5 (3) 4"` から `(1 2.5 4)` が得られます。
3. `(list 1)` の `cdr` を、そのリスト自身に付け替えて、`1` が永遠に続くリストを作り、`write` で出してください。出力を予想してから確かめます。
4. 文字列を1行ずつ読み、行数を数える手続き `count-lines` を書いてください。

### 答え

1 の答えです。

```scheme
(define (write-lines items port)
  (for-each (lambda (item)
              (write item port)
              (newline port))
            items))

(define sink (open-output-string))
(write-lines '("a" #\b 3) sink)
(get-output-string sink)
```

```output
"\"a\"\n#\\b\n3\n"
```

2 の答えです。

```scheme
(define (numbers-in str)
  (let ((port (open-input-string str)))
    (let loop ((x (read port)) (acc '()))
      (cond ((eof-object? x) (reverse acc))
            ((number? x) (loop (read port) (cons x acc)))
            (else (loop (read port) acc))))))

(numbers-in "1 a 2.5 (3) 4")
```

```output
(1 2.5 4)
```

3 の答えです。`(cdr cell)` を `cell` 自身にします。ラベルは `#0=` で、リストは1要素で、その `cdr` が `#0#` です。

```scheme
(define cell (list 1))
(set-cdr! cell cell)
(write cell)
(newline)
```

```output
#0=(1 . #0#)
```

4 の答えです。

```scheme
(define (count-lines str)
  (let ((port (open-input-string str)))
    (let loop ((n 0))
      (if (eof-object? (read-line port))
          n
          (loop (+ n 1))))))

(count-lines "one\ntwo\nthree\n")
(count-lines "")
```

```output
3
0
```
