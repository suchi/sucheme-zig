# 1 はじめに

この章では、sucheme を起動して式を打ち込み、値が返ってくる様子を見ます。ファイルに書いたプログラムを実行する方法も紹介します。

## Scheme と sucheme

Scheme は、1970 年代に生まれた Lisp 系の言語です。文法が小さく、少ない部品を組み合わせてプログラムを作ります。sucheme は、言語の標準仕様である R7RS-small に沿って、Zig で書かれた Scheme の処理系です。このチュートリアルが「Scheme」と書くときは、R7RS-small の Scheme を指します。

このチュートリアルは、C、Python、JavaScript などを使ったことがあり、Lisp 系の言語は初めてという人を想定しています。知っている言語との対比を挟みながら進みます。

## 動かし方

sucheme は、実行ファイル `sucheme` 1つで動きます。入手の方法は、リリースのアーカイブから取り出すか、ソースから `zig build` で作る(実行ファイルは `zig-out/bin/` の下にできます)かのどちらかです。この章は、実行ファイルが手元にあるものとして進みます。

起動のしかたは2通りあります。

- 引数なし: 標準入力から式を読み、式ごとに値を表示します。対話的に試すときに使います。
- ファイル名を1つ渡す: ファイルに書いたプログラムを実行します。

### 式を打って値を見る

引数なしで `sucheme` を打つと、`> ` のプロンプトが出ます。式を打って Enter を押すと、次の行に値が出ます。

```text
$ sucheme
> (+ 1 2)
3
> (* 6 7)
42
```

終わるには、標準入力を閉じます。Unix 系の端末では Ctrl-D です。Windows での操作は、この文書では確かめていません。

以降の章のコードブロックは、このような対話の様子を、入力のブロックと出力のブロックの2つに分けて載せます。コードのブロックを `sucheme` に打ち込むと、すぐ下の出力のブロックと同じ値が返ります。

```scheme
(+ 1 2)
(* 6 7)
```

```output
3
42
```

式を2つ書いたので、値も2つ、1行ずつ出ています。

### 式がすべて値を持つこと

C や JavaScript では、文(`if` や `for`)と式(`1 + 2`)が別のものです。Scheme には、文がありません。プログラムは、式だけでできています。`if` も式で、値を持ちます。

```scheme
(if (> 3 2) "大きい" "小さい")
```

```output
"大きい"
```

文字列の値は、ダブルクォートつきで表示されます。値の表示は、プログラムの中に書いたときの形(`write` の形)です。

### 誤りが出たとき

打ち間違えても、sucheme は止まりません。`error: ` に続けて原因が表示され、次の式を待ちます。

```scheme
(car 5)
```

```output
error: wrong type of argument to car 5
```

数の `5` に `car`(第6章で扱います)を使ったので、誤りです。誤りのあとでも、次の式は普通に動きます。1つのブロックの中で誤りが出ると、そのブロックの残りの式は実行されないので、この文書では誤りを見せる式を単独のブロックに書きます。

```scheme
(+ 1 2)
```

```output
3
```

## ファイルに書いて実行する

ファイルに書いたプログラムは、`sucheme` にファイル名を渡して実行します。次の内容のファイル `hello.scm` を作ります。

```text
(import (scheme write))
(display "Hello, world")
(newline)
```

```text
$ sucheme hello.scm
Hello, world
```

ファイルを実行するときは、式の値は表示されません。画面に出したいものは、自分で `display` で書きます。`(newline)` は改行を書きます。

`display` は、標準の部品の集まりである `(scheme write)` に入っています。使う前に `(import (scheme write))` と書く必要があります。`import` については、第17章で詳しく説明します。いまは「`display` と `newline` を使うおまじない」と思っておいてください。次の例は、これを文書の中で動かしたものです。

```scheme
(import (scheme write))
(display "Hello, world")
(newline)
```

```output
Hello, world
```

プログラムの実行中に誤りが起きると、`error: ` に続けて原因を標準エラーに書き、終了コード 1 で終わります。ファイルが読めないときの終了コードは 66 です。終了コードの一覧は、ソースの [src/main.zig](../../../src/main.zig) の冒頭のコメントにあります。

## この文書の例について

文書の中の Scheme のコードは、すべて自動で実行して、載せた出力と一致することを確かめています([README](../README.md) に仕組みがあります)。同じ章のコードは上から順に1つの処理系で実行されるので、前に定義したものを後で使えます。

## 練習問題

1. `(+ 1 2 3 4)` の値を、頭の中で予想してから、書いてみましょう。Scheme の `+` は、引数をいくつでも取れます。
2. 自分の名前を `display` で書き、そのあとに改行するプログラムを書いてみましょう。

### 答え

1 の答えです。

```scheme
(+ 1 2 3 4)
```

```output
10
```

2 の答えです。名前の部分は、好きな文字列に変えてください。

```scheme
(import (scheme write))
(display "Suchi")
(newline)
```

```output
Suchi
```
