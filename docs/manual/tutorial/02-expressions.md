# 2 式と前置記法

この章では、Scheme の式の書き方を学びます。括弧の使い方、数の計算、比較、真偽値が主な話題です。

## 前置記法

多くの言語では、演算子を数の間に書きます(`1 + 2`)。Scheme では、演算子を先頭に書き、全体を括弧で囲みます。

```text
(演算子 引数1 引数2 ...)
```

```scheme
(+ 1 2)
(- 10 4)
(* 3 4)
```

```output
3
6
12
```

`+` は特別な記号ではなく、ただの手続き(関数)の名前です。`(+ 1 2)` は「手続き `+` を、引数 `1` と `2` で呼ぶ」という意味です。Scheme の呼び出しは、いつでもこの形をしています。括弧の1つ目の要素が呼び出す手続きで、残りが引数です。

前置記法には、利点が2つあります。1つは、演算子の優先順位を覚える必要がないことです。もう1つは、引数の数に制限がないことです。

```scheme
(+ 1 2 3 4 5)
(*)
(+)
```

```output
15
1
0
```

引数が0個の `(+)` は 0、`(*)` は 1 です。足し算と掛け算の単位元を返します。

### 式を入れ子にする

引数には、別の式を書けます。内側の式が先に計算されて、その値が外側の引数になります。

```scheme
(+ 1 (* 2 3))
(* (+ 1 2) (+ 3 4))
```

```output
7
21
```

C などで `1 + 2 * 3` と書くと、優先順位で掛け算が先になります。Scheme では、計算の順序が括弧の入れ子そのものです。書き方が1通りしかないので、曖昧になりません。

### 手続きでないものを呼んだとき

括弧の先頭が手続きでないと、誤りになります。

```scheme
(1 2)
```

```output
error: not a procedure
```

「数のリストを書いたつもり」で括弧を書くと、よくこの誤りになります。リストを書く方法は、第6章で説明します。

### コメント

`;` から行末までは、コメントです。

```scheme
(+ 1 2) ; ここはコメント
```

```output
3
```

## 数

整数は、桁が大きくなってもあふれません。

```scheme
(* 99999999999 99999999999)
(expt 2 100)
```

```output
9999999999800000000001
1267650600228229401496703205376
```

割り算は、割り切れなければ分数(有理数)になります。

```scheme
(/ 8 2)
(/ 7 2)
(/ 1 3)
```

```output
4
7/2
1/3
```

小数点のある数は、浮動小数点数です。正確な数と混ぜると、結果は小数になります。

```scheme
(/ 7 2.0)
(+ 1 2.5)
```

```output
3.5
3.5
```

`7/2` のような正確な数と、`3.5` のような不正確な数の違いは、第11章で詳しく扱います。

整数の割り算には、専用の手続きがあります。`quotient` は商、`remainder` と `modulo` は余りです。

```scheme
(quotient 17 5)
(remainder 17 5)
(modulo -7 3)
(remainder -7 3)
```

```output
3
2
2
-1
```

`modulo` の結果は割る数と同じ符号に、`remainder` の結果は割られる数と同じ符号になります。

そのほか、よく使う手続きです。

```scheme
(max 3 9 4)
(min 3 9 4)
(abs -5)
(gcd 12 18)
(lcm 4 6)
(expt 2 10)
```

```output
9
3
5
6
12
1024
```

## 比較と真偽値

数の比較は `=`、`<`、`>`、`<=`、`>=` です。結果は真偽値で、真が `#t`、偽が `#f` です。

```scheme
(= 3 3)
(< 1 2)
(>= 1 2)
```

```output
#t
#t
#f
```

比較の手続きも、いくつでも引数を取れます。`(< 1 2 3)` は、「1 < 2 かつ 2 < 3」です。

```scheme
(< 1 2 3)
(< 1 3 2)
```

```output
#t
#f
```

C では `1 < 3 < 2` が思った結果にならないことがありますが、Scheme ではこの書き方で正しく範囲の検査ができます。

数を調べる手続きの名前は、`?` で終わるのが決まりです。

```scheme
(zero? 0)
(even? 10)
(odd? 10)
(number? 1)
(number? "1")
```

```output
#t
#t
#f
#t
#f
```

### 偽になる値は #f だけ

真偽値を求める場面(第5章の `if` など)で、偽として扱われるのは `#f` だけです。`0`、空のリスト、空の文字列は、どれも真です。JavaScript や Python の感覚と違うので、注意してください。

`not` は真偽を反転します。`#f` 以外の値に使うと、`#f` を返します。

```scheme
(not #f)
(not #t)
(not 0)
```

```output
#t
#f
#f
```

## 練習問題

1. 数式 `(3 + 4) * 5 - 6 / 2` を、Scheme の式に書き直してください。
2. 2000 を 7 で割った商と余りを、それぞれ求めてください。
3. `(< 1 2 3)` の結果は `#t` でした。`(< 1 2 2)` の結果は、予想してから試してください。

### 答え

1 の答えです。内側から順に、`(+ 3 4)`、それに 5 を掛け、`(/ 6 2)` を引きます。

```scheme
(- (* (+ 3 4) 5) (/ 6 2))
```

```output
32
```

2 の答えです。

```scheme
(quotient 2000 7)
(remainder 2000 7)
```

```output
285
5
```

3 の答えです。`<` は「真に小さい」なので、2 と 2 は条件を満たしません。

```scheme
(< 1 2 2)
(<= 1 2 2)
```

```output
#f
#t
```
