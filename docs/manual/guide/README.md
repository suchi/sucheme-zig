## この文書の例について

コマンドの例は、`console` のブロックで書きます。`$ sucheme` で始まる行が実行するコマンドで、その下の行が期待する出力です。`zig build check-examples` が、実行ファイルを実際に起動して、出力と終了コードを比べます。決定の経緯は [ADR-0048](../../adr/0048-run-the-examples-of-the-user-documentation.md) にあります。

```console
$ sucheme hello.scm
Hello, world
```

読み方は次のとおりです。

- 例のコマンドは、この文書の `examples/` ディレクトリを作業ディレクトリにして走ります。例に出てくる `hello.scm` などは、そこに置いてあるファイルです。
- 期待する出力は、標準出力に続けて標準エラーを並べたものです。2つを別の行に書き分けてはいません。
- 終了コードが 0 でないコマンドは、出力の最後に `[exit 66]` のような行を書きます。この行はコマンドの出力ではなく、検査のための書き方です。書いていなければ 0 です。
- 走らせるのは `sucheme` の呼び出しだけです。シェルを通さずに、引数を空白で区切って渡します。引用符、`|`、`>`、`$` などは書けません。

REPL の対話の様子(標準入力を読むもの)と、`sh` で打つコマンド(アーカイブの展開など)は、この検査の外にあります。それらは `text` のブロックで書き、検査していないことを、その場で断ります。
