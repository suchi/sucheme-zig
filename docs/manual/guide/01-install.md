# 1 入手と実行

sucheme は、実行ファイル `sucheme` 1つで動きます。入手の方法は、リリースのアーカイブから取り出すか、ソースから作るかのどちらかです。

## リリースのアーカイブ

リリースは、プラットフォームごとのアーカイブと、`SHA256SUMS` からなります。アーカイブの名前は `sucheme-v<版>-<ターゲット>` で始まり、Linux と macOS は `.tar.gz`、Windows は `.zip` です。どのターゲットがあるかは、リリースごとのノート(たとえば [v1.0.0](../../releases/v1.0.0.md))の「成果物」の表にあります。リポジトリは private なので([ADR-0020](../../adr/0020-repository-visibility-private.md))、リリースを取得できるのは、リポジトリにアクセスできる人だけです。

アーカイブを展開すると、`sucheme-v<版>-<ターゲット>/` というディレクトリが1つでき、その下に実行ファイル(Windows は `sucheme.exe`)、`LICENSE`、第三者の表示 `THIRD-PARTY-NOTICES.txt` が入っています。標準ライブラリは実行ファイルに埋め込んであり、別のファイルはありません。

次の例は、Linux x86_64 のアーカイブを展開して実行します。この例は `check-examples` の検査の外にあります。リリースノートの使い方の節にある例で、この文書を書くときに、アーカイブから実行する手順は確かめていません。

```text
tar xzf sucheme-v1.0.0-x86_64-linux-musl.tar.gz
./sucheme-v1.0.0-x86_64-linux-musl/sucheme --version
```

### 取得の確認

ダウンロードしたファイルが壊れていないことは、`SHA256SUMS` と同じディレクトリで次を実行して確かめます。

```text
sha256sum -c SHA256SUMS
```

`SHA256SUMS` は成果物と同じ場所から配るので、破損や取り違えには効きますが、改ざんには効きません。署名と attestation は行っていません([ADR-0034](../../adr/0034-release-shape.md))。Windows での確かめ方は、この文書では確かめていません。

## ソースからのビルド

必要なのは Zig だけです。依存パッケージはありません。Zig の版は、リポジトリの根の [.zigversion](../../../.zigversion) に書いてあり、その版と一致するものを使います(版が違うと、ビルドが断ります)。

```text
zig build
```

実行ファイルは `zig-out/bin/sucheme`(Windows は `sucheme.exe`)にできます。ビルドしながら実行するには、引数を `--` のあとに書きます。

```text
zig build run -- hello.scm
```

引数なしの `zig build run` は REPL になります。

実行ファイルは、置いた場所によらず動きます。標準ライブラリを埋め込んでいるからです。作業ディレクトリが関わるのは、自分で書いたライブラリを探すときだけです([5 ライブラリ](05-libraries.md))。
