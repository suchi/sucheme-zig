# 7 準拠の状況と既知の制限

この章は、どこまで動くかと、動かないものへの道案内です。内容は日々変わるので、写さずに、正の場所へのリンクで書きます。

## どこまで動くか

- 段階ごとの進み具合と、最新のリリース: [docs/roadmap.md](../../roadmap.md) の「現在地」。
- R7RS の識別子が束縛されているかと、準拠スイートの結果: [準拠マトリクス](../../status/conformance.md)。生成物で、`zig build report` で作り直します。
- リリースごとにできるようになったこと: リリースノート(たとえば [v1.0.0](../../releases/v1.0.0.md))。

準拠スイートが通っても、スイートの外の振る舞いは、準拠を保証しません。範囲の定め方は、リリースノート(たとえば [v1.0.0](../../releases/v1.0.0.md))の冒頭にあります。

## 既知の制限

制限は、リリースノートの「既知の制限」の節に、リリースごとにまとめてあります([v1.0.0](../../releases/v1.0.0.md))。後の版で直したものは、その版のノートに書きます。直すかどうかを決めていないものは、[docs/design/open-questions.md](../../design/open-questions.md) と [docs/roadmap.md](../../roadmap.md) の項目にあります。

この文書の章で触れたものを挙げます。

- REPL の行編集は、POSIX の端末での複数行にわたる式の編集と、終了で消える履歴だけです([3 REPL](03-repl.md) の「行の編集」)。履歴の保存、補完、括弧の対応の表示、Windows での編集は、まだありません。[docs/roadmap.md](../../roadmap.md) の段階7の項目です。
- 標準入力のプログラム(`sucheme -`)は、まだありません。終了コード 69 になります([2 コマンドライン](02-command-line.md))。
- 実行時のエラーには、位置が付きません。[docs/roadmap.md](../../roadmap.md) の段階8の項目です。
- マクロが導入したトップレベルの定義は、衛生的ではありません。利用側の同じ綴りのトップレベルの変数を書き換えます。[docs/roadmap.md](../../roadmap.md) の段階6の項目に、経緯があります。
- 入力の大きさの上限(REPL の保留は 65536 バイト、ファイルは 1 MiB)と、ヒープの上限があります。ヒープの上限に届くと `heap limit exceeded` で止まります。

## 問題を見つけたら

issue で知らせてください。リポジトリは private なので([ADR-0020](../../adr/0020-repository-visibility-private.md))、issue を扱えるのは、アクセス権のある方だけです。
