# 3 REPL

引数なしで `sucheme` を起動すると、REPL(read-eval-print loop)になります。式を1つ読み、評価し、値を出す、という繰り返しです。

## 式を打つ

プロンプトは `> ` です。式を打って Enter を押すと、次の行に値が出ます。次の図は、端末での見え方です。この対話は `check-examples` の検査の外にあります(検査は標準入力を渡して実行ファイルを走らせません)。入力の行は、実行ファイルに式を流し込んだ出力から、端末が表示する形に組み立てたものです。

```text
$ sucheme
> (+ 1 2)
3
> (define (twice x)
... (* x 2))
> (twice 21)
42
> (car 5)
error: wrong type of argument to car 5
> (twice 1)
2
```

次のことが、上の対話から分かります。

- 定義は何も出力しません。
- 式が閉じていない行(括弧が足りない行)で Enter を押すと、プロンプトが `... ` に変わり、続きを待ちます。閉じたところで、溜めた入力の全体を評価します。端末では、Ctrl-C で、溜めた入力を捨てて `> ` に戻れます(下の「行の編集」)。標準入力をパイプやファイルにしたときは、継続行をやめる方法はありません。
- 誤りは `error: ` に続けて説明が出て、その式の評価だけが終わります。REPL は止まらず、次の式を読みます。

`check-examples` は、REPL と同じ評価の入口で、コードブロックの出力を確かめています。次のコードブロックは、REPL に1行ずつ打ったときと同じ値を出します。

```scheme
(define x 5)
(* x x)
"a string"
(values 1 2)
(values)
```

```output
25
"a string"
1
2
```

値が複数のときは1行に1つずつ、0 個なら何も出ません。

## 使えるものは `(scheme base)` だけ

REPL の最初の環境は `(scheme base)` です。`display` や `exit` のように、ほかのライブラリにあるものは、`import` してから使います。

```scheme fresh
(display "hi")
```

```output
error: unbound variable: display
```

```scheme
(import (scheme write))
(display "hi")
(newline)
```

```output
hi
```

`display` を `import` する前の呼び出しは `unbound variable` の誤りです。どのライブラリに何があるかは [5 ライブラリ](05-libraries.md) を見てください。

## 終わり方

標準入力を閉じると終わります。Unix 系の端末では Ctrl-D です(Windows での操作は、この文書では確かめていません)。`(import (scheme process-context))` のあとで `(exit)` を呼んでも終わります。

```text
> (import (scheme process-context))
> (exit 7)
```

`exit` の引数が、`sucheme` の終了コードになります。式の途中で標準入力が尽きたときは、`error: unexpected end of input` を出して終わります。

## 入力の長さの上限

溜めている入力(継続行を含む)の合計は、改行を入れて 65536 バイトまでです。超えると `error: the input does not fit in 65536 bytes, newline included` を出して、溜めた入力を捨てます。大きなプログラムは、REPL に貼らずにファイルに書いて実行します([4 ファイルの実行](04-running-files.md))。

## 行の編集

Linux や macOS などの端末で起動すると(標準入力と標準出力の両方が端末のとき)、打っている行を Emacs と同じキーで編集できます。標準入力をパイプやファイルにしたときと、Windows では、行の編集は無く、これまでどおり1行ずつ読みます。macOS での動作は、この文書では確かめていません。

| キー | 働き |
| --- | --- |
| Ctrl-A、Home | 行頭へ |
| Ctrl-E、End | 行末へ |
| Ctrl-B、左矢印 | 1文字戻る |
| Ctrl-F、右矢印 | 1文字進む |
| Alt-B | 1語戻る |
| Alt-F | 1語進む |
| Backspace | カーソルの前の文字を消す |
| Ctrl-D、Delete | カーソルの文字を消す。Ctrl-D は、空の行では入力の終わり |
| Ctrl-K | 行末までを切り取る |
| Ctrl-U | 行頭までを切り取る |
| Ctrl-W | カーソルの前の、空白で区切った語を切り取る |
| Alt-D | 次の語の終わりまでを切り取る |
| Alt-Backspace | カーソルの前の語を切り取る |
| Ctrl-Y | 最後に切り取ったものを貼り付ける |
| Alt-Y | Ctrl-Y の直後に、貼り付けたものを、1つ前に切り取ったものに替える |
| Ctrl-T | カーソルの前後の文字を入れ替える |
| Ctrl-_ | 1つ前の編集を取り消す |
| Ctrl-P、上矢印 | 履歴の1つ前の式 |
| Ctrl-N、下矢印 | 履歴の1つ後の式。最後まで来ると、打ちかけの行に戻る |
| Ctrl-R | 履歴を後ろから検索する。続けて打つ文字で絞り込み、もう一度 Ctrl-R で、さらに前の一致へ。Enter でその式を実行し、Ctrl-G で検索をやめる。ほかのキーは、見つかった式を行に入れて、そのキーとして働く |
| Ctrl-C | 打っている行と、溜めている継続行を捨てて、`> ` に戻る |
| Enter | 行を確定する |

Alt の代わりに、Esc を押してから文字を押しても同じです(Esc のあとに B で、Alt-B)。Esc だけを押したときは、次のキーを待ちます。

閉じた式は、継続行も含めて1つずつ履歴に残ります。履歴は、sucheme を終えると消えます。

次のことは、まだできません。

- 継続行で Enter を押した前の行には、戻って直せません。複数の行にまたがる式は、履歴に残りますが、上下の矢印と Ctrl-R では呼び出せません。
- 補完と、括弧の対応の表示はありません。Tab は、そのまま文字として入ります。
- 全角の文字を含む行では、カーソルの位置が画面とずれます。
- 端末の幅より長い行は、折り返さずに、横にずらして表示します。

行の編集の範囲は、[7 準拠の状況と既知の制限](07-limitations.md) にもまとめてあります。
