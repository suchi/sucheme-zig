# スライス 3d: 文字列の比較(R7RS 6.7)。`string=?` `string<?` `string>?` `string<=?`
# `string>=?`。引数を何個でも取り、隣り合う組がすべて成り立つときに真である。順序は、
# 文字の列の辞書式順序で、文字はコードポイントの順である。短い文字列は、同じ接頭辞を持つ
# 長い文字列より小さい。大文字小文字を区別しない `string-ci=?` などは、段階4が足す。

(string=? "abc" "abc")

# 引数が1つなら、比べる相手が無いので真である。

#t

# 比べても、文字列は変わらず、結果は真偽値である。
(define s (make-string 2 #\a)) (list (string=? s s) (string<? s s) (string<=? s s) s)
(#t #f #t "aa")
