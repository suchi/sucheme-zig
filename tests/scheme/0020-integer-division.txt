# スライス 1k の単位 K4: 整数除算と `number?`。
# `quotient` と `remainder` は0に向かう切り捨て除算、`modulo` は床除算である
# (R7RS 6.2.6)。`remainder` の符号は被除数に、`modulo` の符号は除数に従う。
# 除数が0なら0除算のエラーである。最小の整数を -1 で割る `quotient` は、結果が
# fixnum に収まらず bignum になる。`remainder` と `modulo` は 0 になる。

# 実演。階乗。20 は fixnum に収まり、21 からは bignum になる。

# 実演。10進の桁の和。`quotient` と `modulo` で桁を取り出す。
(define (digits n) (if (= n 0) 0 (+ (modulo n 10) (digits (quotient n 10))))) (digits 9876)
30
