# スライス 1k の単位 K6: プリミティブのエラーの一覧。
# 1k の各プリミティブ × エラーの種類(個数、型、範囲、0 除算、整数の溢れ)の表である。
# 整数のあふれは `quotient` だけが報告する。`+ - *` は、4f から bignum を返す。
# 検査の順序は、引数の個数(機械が表で検査する)、すべての引数の型、値の範囲で、
# 値に左右されずエラーが決まる。引数の式は呼び出しより先に評価される。
# 0008 と 0017 から 0023 に同じ入力のケースがあるものは、なるべく重ねない(2件だけ
# 重なっている: `(remainder 1 'a)` と `(string-ref "abc" #\a)`)。ここは
# それらを補い、全プリミティブと全種類の組を埋める。ケースは機械的に作った
# 部分(個数と型)と、手で書いた部分(範囲、溢れ、順序、呼び出しの経路)に分かれる。
# エラーのあとも REPL が続行することは、1ケース1行のこの形式では書けないので、
# src/sucheme.zig の単体テストが固定する。

# 個数の誤り。下限を下回る場合、上限を超える場合。個数は型より先に検査されるので、
# 引数が型の合わない値でも個数のエラーになる。+ * list vector は何個でも取る。
