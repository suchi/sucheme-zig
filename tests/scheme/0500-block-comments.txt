# スライス 5a: ブロックコメント `#|` ... `|#`(R7RS 2.2、7.1.1 の <nested comment>)。
# 入れ子にでき、空白を置ける場所ならどこにでも書ける。
# 1ケースは1行の入力なので、複数行にまたがるコメントは src/reader.zig の単体テストが
# 受け持つ。

#| コメント |# 1
1

(+ 1 #| 2 |# 3)
4

# 内側の `|#` は、内側のコメントだけを閉じる。
#| a #| b |# c |# 1
1

# コメントの中の文字列、行コメント、括弧は、何も始めない。
(list 1 #| " ; ( |# 2)
(1 2)

# R7RS 2.2 の例。
#| (define (fact n) (if (= n 0) 1 (* n (fact (- n 1))))) |# 'done
done

# コメントだけの入力は、何も評価しない。
#| コメントだけ |#
<no output>

# 閉じていないコメントは、入力の終わりで誤りになる。
#| 閉じない
error: unexpected end of input

#| a #| b |# 閉じない
error: unexpected end of input

# 閉じる記号だけでは、コメントにならない。
|# 1
error: unreadable token
