# スライス 1k の単位 K6: 実演プログラム。
# 1k で入った束縛(ペア、リスト、述語、整数除算、文字・文字列・ベクタの操作)と
# `define` `lambda` `if` だけで書いたプログラムが、通しで動くことを固定する。
# `let` `cond` `and` `or` `do` は段階3まで無い(可変長引数の `lambda` は、書いた
# 時点では無く、2a で入った)ので、補助の手続きは `define` で並べる。1ケースは1行で、1つの `Interpreter` が評価する。
# 各プリミティブの振る舞いと文言は 0017 から 0023 と 0025 が固定する。ここは、
# それらを組み合わせたときに、結果が正しく、GC を越えても壊れないことを見る。
# 実行器は全ケースを、1ステップごとに GC するモードでも走らせる。
