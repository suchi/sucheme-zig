# スライス 2k: syntax-rules の誤りは、定義の時点で報告する。2l が入れる形(入れ子の
# 省略記号、省略記号の後の固定パターン、非真正リスト、ベクタ、定数パターン、
# テンプレートの省略記号のエスケープ、利用者指定の省略記号)は、黙って別の意味に
# 読まず、まだ扱えないと報告する。それらの行は 2l が書き換える。

(define-syntax m (syntax-rules () ((_ x) 1))) (m)
error: bad syntax: no rule of m matches the form

(define-syntax m (syntax-rules () ((_ a a) 1)))
error: bad syntax-rules: duplicate pattern variable: a

(define-syntax m (syntax-rules () ((_ a ...) a)))
error: bad syntax-rules: a needs as many ellipses in the template as in its pattern

(define-syntax m (syntax-rules () ((_ a) (a ...))))
error: bad syntax-rules: an ellipsis must follow a template with a pattern variable that an ellipsis followed

(define-syntax m (syntax-rules () ((_ ... a) 1)))
error: bad syntax-rules: an ellipsis must follow a pattern

(define-syntax m (syntax-rules () ((_ a) ...)))
error: bad syntax-rules: an ellipsis must follow a template

(define-syntax m (syntax-rules () ((_ a) (list ...))))
error: bad syntax-rules: an ellipsis must follow a template with a pattern variable that an ellipsis followed

(define-syntax m (syntax-rules () ((_ (a ...) (b ...)) '((a b) ...)))) (m (1 2) (3))
error: bad syntax: a and b matched different numbers of forms but an ellipsis repeats them together

(define-syntax m (syntax-rules () (_ 1)))
error: bad syntax-rules: a pattern must be a list that starts with an identifier

(define-syntax m (syntax-rules () ((1) 1)))
error: bad syntax-rules: a pattern must be a list that starts with an identifier

(define-syntax m (syntax-rules () ((_))))
error: bad syntax-rules: a rule must be (pattern template)

(define-syntax m (syntax-rules (1) ((_) 1)))
error: bad syntax-rules: a literal must be an identifier

(define-syntax m (syntax-rules))
error: bad syntax-rules: expected (syntax-rules (literal ...) rule ...)

(define-syntax m 1)
error: bad define-syntax: the transformer must be a syntax-rules form

(define-syntax 1 (syntax-rules ()))
error: bad define-syntax: the keyword must be an identifier

(define-syntax m)
error: bad define-syntax: expected (define-syntax keyword transformer)

(syntax-rules () ((_) 1))
error: bad syntax-rules: it is only allowed as the transformer of a syntax definition

# 2l が入れる形。
