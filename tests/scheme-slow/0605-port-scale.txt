# 手間で伸びること、上限を超える書き込みが止まらずに誤りになること、使い終えたポートの領域が
# 回収されること。実行に時間がかかるので `zig build test-scheme -Dslow=true` のときだけ走る
# (docs/plans/0007-test-tiers.md)。同じ論理を小さい規模で通す双子が

# 1ステップごとに GC するモードの2回走る。ランナーの上限は 64 MiB である。
