# 括弧の対応の共有一覧

`cases.tsv` は、`src/line_editor/parens.zig`(Zig)と `web/parens.mjs`(JavaScript)が、同じ入力で同じ結果を返すことを固定する一覧である。両方のテストが、このファイルを読む。

1行が1つの入力である。タブで2つの欄に分ける。

- 1欄目: 入力のテキスト。バックスラッシュは `\\`、改行は `\n`、タブは `\t`、CR は `\r` と書く。
- 2欄目: カーソルの位置 0 から長さまで、それぞれの `matching` の結果を、空白で区切って並べる。相手の位置か、無いときは `-`。

テキストは ASCII だけにする。位置の単位が、Zig はバイト、JavaScript は UTF-16 の符号単位で、ASCII のときだけ一致するためである。マルチバイトの文字は、それぞれの言語のテストが別に確かめる。
